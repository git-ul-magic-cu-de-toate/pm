Instructions:

* Setup:
- Import the "LiquidCrystal_I2C-1.1.2" library from the "libs" folder:
	> In the Arduino IDE, go to Sketch > Include Library > Add .ZIP Library. 
	From the drop down list, select the "Add .ZIP Library" option

* Running:
- Connect a power source to the Arduino (e.g.: a PC or a 9V battery)
- Enjoy!
